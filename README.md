# DRIFT ARENA 🏁

Браузерная 3D-игра про дрифт: реалистичная физика, 6 машин, полноценный тюнинг,
настройка графики, три режима игры. Работает на three.js (WebGL2), без сборки —
просто поднять статический сервер.

## Запуск в браузере

```bash
npm install     # ставит three.js
npm start       # http://localhost:3000
```

Или любым другим статическим сервером из корня репозитория.

## 🪟 Windows 10/11 — запуск как приложение

### 1. Установка игры одним файлом (рекомендуется)

Двойной клик по **`INSTALL.bat`** — установщик делает всё сам:

* копирует игру в `%LOCALAPPDATA%\Programs\DRIFT ARENA`
  (**Node.js и npm не нужны** — внутри копии всё уже собрано);
* создаёт ярлык в меню «Пуск» и на рабочем столе, с иконкой игры;
* добавляет игру в «Параметры → Приложения» — удаляется оттуда же;
* сразу открывает игру в окне без адресной строки.

После установки игра запускается из **меню «Пуск» → DRIFT ARENA**
(или с ярлыка на рабочем столе).

**Удаление:** меню «Пуск» → DRIFT ARENA → `Uninstall DRIFT ARENA`
или «Параметры → Приложения → DRIFT ARENA → Удалить».
Деинсталлятор снимает ярлыки, запись в списке программ и папку с игрой.

> Установщик использует готовую папку `app/` из репозитория. Если её нет —
> соберите одной командой: `npm run build:app`.

### 2. Автономный файл (ничего устанавливать не нужно)

Двойной клик по **`DRIFT-ARENA.html`** — игра целиком в одном файле
(~700 КБ), работает без интернета, без Node.js и без прав администратора.
Можно положить на рабочий стол, на флешку, отправить другу.

### 3. Лаунчеры из папки с игрой (окно без адресной строки)

* **`DRIFT-ARENA.vbs`** — двойной клик: поднимает сервер скрыто и открывает
  игру в окне `--app` (чёрное окно консоли не показывается);
* **`DRIFT-ARENA.bat`** — то же, но с видимой консолью (удобно, если что-то
  не запускается: покажет, чего не хватает).

Лаунчер сам определяет браузер по умолчанию и открывает `--app` в
**Edge, Chrome или Яндекс.Браузере**; если Node.js не установлен —
автоматически открывает автономный `DRIFT-ARENA.html`.
Остановить сервер: `taskkill /f /im node.exe`.

### 4. Настоящее приложение Windows (PWA: свой ярлык, офлайн-режим)

```bash
npm start
```

затем в Edge/Chrome/Яндекс.Браузере нажать
**«⬇ УСТАНОВИТЬ КАК ПРИЛОЖЕНИЕ WINDOWS»** в главном меню игры
(или ⋯ → Приложения → Установить этот сайт как приложение).
После установки игра открывается из меню «Пуск» в отдельном окне,
работает офлайн (service worker) и хранит рекорды локально.

## Пересборка автономной версии и установщика

```bash
npm run build:app   # DRIFT-ARENA.html + папка app/ для INSTALL.bat
npm run icons       # перегенерировать иконки PWA
npm start           # разработка: http://localhost:3000
```

`npm run build:app` делает две вещи:
* `DRIFT-ARENA.html` — вся игра в одном файле (file://, без Node.js);
* `app/` — готовая к установке папка: `index.html` с инлайном CSS+JS
  (поэтому `node_modules` и `npm install` не нужны), свой `server.js`,
  service worker, иконки, лаунчеры, деинсталлятор и помощник ярлыков.
  Именно её копирует `INSTALL.bat`. Папка лежит в репозитории, поэтому
  установка работает без Node.js вообще.

## Что внутри

**Физика (своя, не аркада):**
- 4 колеса независимо, модель шин «магическая формула Пажейка» с насыщением
- перенос веса (продольный + поперечный) с учётом жёсткости пружин и высоты ЦТ
- нагрузочная чувствительность шин, температура и износ сцепления
- релаксация шины (инертность боковой силы), самоцентрирующий момент
- круг сцепления: тяга на задней оси «съедает» боковую силу → power oversteer
- ручник срывает заднюю ось, дифференциал с преднатягом, аэродинамика + антикрыло
- коробка передач с кривой момента, отсечкой, наддувом, задним ходом
- трамплины с реальным запуском (производная высоты рельефа), грунт с другим сцеплением

**Машины (6):** Kouki GT-S, Hachi-Roku, MK4 RZ, Fox GT 5.0, E30 M3, Evo Rally.
У всех разные масса, мощность, моменты, КПП, привод (RWD/AWD), геометрия подвески.

**Тюнинг:** резина (4 компaунда), пружины перед/зад, клиренс, распред. тормозов,
преднатяг дифференциала, антикрыло, угол руля, схождение, главная пара — всё влияет на физику.

**Гараж:** цвет кузова/дисков/суппортов, металлик и лак, тонировка, 4 типа дисков.
Машину можно вертеть на сцене (шейдерное небо + студийный свет).

**Графика:** пресеты Low→Ultra, масштаб разрешения, тени, bloom, motion blur,
FXAA, плотность дыма, следы шин, дальность прорисовки, время суток (день/закат/ночь
с фарами и фонарями), FOV и эффект скорости, 3 камеры.

**Режимы:** свободная езда, дрифт-зона (90 с, множители за длинный занос),
Time Attack (3 круга через чекпоинты). Рекорды в localStorage.

**Эффекты:** следы шин на асфальте (ленты с затуханием), дым от пробуксовки,
пыль на грунте, искры от ударов, выбитые конусы, синтез звука двигателя/шин/ветра
на WebAudio, тряска камеры, крены кузова от ускорений.

## Управление

W/S газ-тормоз, A/D руль, Space ручник, Shift/Ctrl передачи (ручной режим),
C камера, R респавн, Tab быстрый тюнинг, M звук, Esc пауза. Есть геймпад и тач-кнопки.

## Структура

```
index.html        разметка интерфейса
css/style.css     стили
js/config.js      машины, тюнинг, настройки, сохранения
js/physics.js     физика автомобиля и столкновения
js/carbuilder.js  процедурные модели машин и колёс
js/world.js       трасса, скейд-пад, трамплины, объекты
js/env.js         небо, свет, время суток, отражения
js/textures.js    процедурные текстуры
js/effects.js     следы шин, частицы
js/audio.js       синтез звука
js/input.js       клавиатура/тач/геймпад
js/ui.js          меню, гараж, настройки, HUD
js/showroom.js    3D-гараж
js/main.js        игровой цикл, режимы, счёт
server.js         статический сервер
build.js          сборка DRIFT-ARENA.html и папки app/
tools/launchers.js  генераторы .bat/.vbs (корневые и для app/)
INSTALL.bat       установщик: папка в Programs, ярлыки, запись в программах
app/              готовая к установке копия игры (результат сборки)
```
